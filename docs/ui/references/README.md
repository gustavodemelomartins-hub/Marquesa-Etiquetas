# Arquivos de referência

Guarde aqui apenas arquivos visuais realmente recebidos ou produzidos para a
trilha do **Sistema Marquesa**.

Crie a pasta do domínio somente quando chegar a primeira referência:

```text
references/<dominio>/AAAA-MM-DD_<tela>_<viewport>_<sequencia>.<ext>
```

Exemplo:

```text
references/estoque/2026-09-10_estoque-total_mobile_01.png
```

Todo arquivo precisa de uma entrada correspondente em
`../REFERENCE-CATALOG.md`. Não copie ativos externos sem necessidade e não
guarde secrets, dados pessoais reais ou exportações operacionais nesta pasta.
