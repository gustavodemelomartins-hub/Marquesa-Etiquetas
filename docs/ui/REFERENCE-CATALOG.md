## Domínios para classificação

Use o domínio real mais próximo: `shell-plataforma`, `etiquetas`, `estoque`,
`catalogo`, `vendas`, `clientes`, `financeiro`, `revendedoras-maletas`,
`garantias`, `inventario`, `saidas-sem-faturamento`, `nuvemshop`,
`reconciliacao` ou `analytics`.

Uma pasta física em `references/` só deve ser criada quando chegar o primeiro
arquivo daquele domínio.
