# Referências externas

Inspiração que vem de **fora** do Sistema Marquesa: outro produto, site,
dashboard, print de concorrente, peça gráfica. Print da nossa própria tela não
entra aqui — vai para `03-screens/<tela>/images/`.

## Onde colocar

Uma pasta por domínio, já criadas: `dashboard/`, `vendas/`, `clientes/`,
`revendedoras/`, `estoque/`, `reparos/`, `personalizacao/`. Referência que não
serve a um domínio só fica na raiz de `02-references/`.

Nome do arquivo:

```text
AAAA-MM-DD_<origem>_<assunto>_<sequencia>.<ext>
2026-09-10_notion_tabela-filtravel_01.png
```

## Registro

Toda referência salva ganha uma linha no índice abaixo. Imagem sem linha é
imagem perdida: ninguém sabe o que o Gustavo quis mostrar nela.

| Data | Arquivo | Domínio | O que chamou atenção | Telas afetadas |
|---|---|---|---|---|
| | | | | |

O campo **"o que chamou atenção"** é o mais importante. Uma imagem não diz
sozinha se o que interessa é o layout, a cor, a densidade de informação ou o
fluxo. Sem essa frase, a referência não é acionável.

Se a referência também for link, registre a URL na coluna `Arquivo`.
