# Componentes

Padrão visual que aparece em mais de uma tela. Cada pasta guarda o papel do
componente, variantes, estados e regras de uso — mais as imagens dele.

`header/` · `navigation/` · `cards/` · `filters/` · `tables/` · `modals/` ·
`charts/` · `badges/` · `payment-composer/` · `item-price-editor/` ·
`product-gallery/`

O [Design System V2](design-system-v2.md) já é aplicado ao protótipo HTML por
`prototype/system.css`, `system.js` e a base de Vendas. As pastas registram o
vocabulário e os estados. A consolidação em componentes React continua na
trilha prevista do Master Plan.

O que já existe em React está em `docs/ui/COMPONENT-INVENTORY.md`.
