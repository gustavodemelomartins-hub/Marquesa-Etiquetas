**Nada nestas listas é autorizado a ser implementado.** Entrar aqui significa
"registrado e preservado", não "aprovado". A passagem de ideia para trabalho é
um pedido humano explícito, e o encaixe acontece na fase correspondente do
Master Plan — não porque a ideia é boa nem porque está parada há tempo.
