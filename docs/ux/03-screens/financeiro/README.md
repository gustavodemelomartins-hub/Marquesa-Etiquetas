# Tela: Financeiro

O protótipo [master.html](master.html) propõe a cobertura de `A receber`,
recebimentos e histórico auditável a partir do fluxo canônico de Vendas.

O estado financeiro é derivado dos recebimentos pagos. O saldo não recebido
permanece em `A receber`, sem geração de parcelas. Cada pagamento usa a data
efetiva; correção preserva o evento anterior; nenhuma ação movimenta estoque.

Não existe mockup próprio recebido para esta tela. Portanto, toda a composição
visual está **READY FOR GUSTAVO REVIEW**, sem aprovação presumida. Dados e ações
são demonstrativos e não definem rota, tabela ou implementação.
