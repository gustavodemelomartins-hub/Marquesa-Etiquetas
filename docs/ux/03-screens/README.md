# Telas

Uma pasta por tela. Todas seguem o mesmo formato — README, `images/`,
`states.md`, `rules.md`, `metrics.md`, `api-needs.md`, `open-questions.md` —
para que qualquer material chegue sempre no mesmo lugar, em qualquer tela.

| Tela | Pasta |
|---|---|
| Dashboard | [dashboard/](dashboard/) |
| Vendas | [vendas/](vendas/) |
| Clientes | [clientes/](clientes/) |
| Revendedoras | [revendedoras/](revendedoras/) |
| Estoque | [estoque/](estoque/) |
| Reparos | [reparos/](reparos/) |
| Personalização | [personalizacao/](personalizacao/) |

Tela nova: copie a pasta de uma existente, esvazie as tabelas, e adicione a
linha no índice acima e em [00-index.md](../00-index.md). Não crie tela sem
material — pasta vazia sem dono vira ruído.

O inventário do que **já existe** hoje (legado e React) está em
`docs/ui/SCREEN-INVENTORY.md`, não aqui.
